# ALT5 (ANTI_ALT3) Concept & Implementation Report

**Date:** 2026-03-08  
**Scope:** Forecast layer only (no execution strategy changes)

## 1. Business Idea

`ALT5` is a forecast-only strategy defined as **inversion of legacy `ALT3` direction**:

- if `h30_alt3_direction = up` -> `h30_alt5_direction = down`
- if `h30_alt3_direction = down` -> `h30_alt5_direction = up`

The goal is to exploit periods where Alt3 systematically underperforms.

## 2. Runtime Filters (ENV)

ALT5 generation is controlled by environment variables:

- `ALT5_ENABLED` (`1`/`0`, default `1`)
- `ALT5_ALLOWED_HOURS` (CSV UTC hours, e.g. `3,9,11,19`; empty = all hours)
- `ALT5_MIN_ADX` (float threshold for `adx_value`, default `0`)

Behavior:

1. Alt5 is skipped if disabled.
2. Alt5 is skipped if hour filter is set and current UTC hour is not included.
3. Alt5 is skipped if ADX is missing or below `ALT5_MIN_ADX`.
4. Otherwise Alt5 direction is generated by inverting Alt3.

## 3. Data Model & DB

Added fields in `price_forecasts`:

- `h30_alt5_direction text`
- `h30_alt5_correct boolean`

Migration:

- `migrations/023_alt5_variant.sql`

Model support:

- `app/models/forecast.py` includes `h30_alt5_direction`, `h30_alt5_correct`
- `to_db_row()` persists `h30_alt5_direction`

## 4. Verification

`app/forecast/verifier.py` now validates Alt5 similarly to other alt variants:

- computes actual H30 direction from realized price move
- writes `h30_alt5_correct`
- emits `AltVerified(variant="alt5", ...)` for lifecycle feedback

## 5. API/Stats Integration (Backend)

`app/dashboard.py` (`/api/forecasts-history`) enriched with:

- `recommended_alt5`
- `alt5_stats` (total / verified / correct / accuracy)

`app/main.py` lifecycle verification handler accepts `alt5` variant key.

`app/storage/forecast_repo.py` dedup signature includes `h30_alt5_direction`.

## 6. Frontend Integration

Implemented in `ibkr-trading-fronend`:

1. **Forecast History** (`/admin/forecasts/history`)
   - strategy dropdown includes `Alt5`
   - row mapping uses `h30_alt5_direction/h30_alt5_correct`
   - summary cards compute Alt5 metrics

2. **Binary Signals** (`/admin/binary-signals`)
   - page/header includes Alt5
   - active cards/blocks for Alt5 signals
   - API returns Alt5 fields and 48h accuracy bucket for Alt5

## 7. Important Notes

1. Weekend behavior is expected: forecast generation is skipped when FX market is closed.
2. After changing ALT5 filters, historical ALT5 fields may require explicit backfill/rebuild for apples-to-apples comparisons.
3. This update does not change execution strategy selection by itself; it adds forecast-layer analytics/signal visibility.
