## 1. CandlestickPatternDetector

**Файл:** `app/market_data/candlestick_patterns.py`

### Источник идеи
- TA-Lib (https://ta-lib.org/) — C библиотека с 61 свечным паттерном
- github.com/edgetrader/candlestick-pattern — Python обёртка над TA-Lib

### Что реализовано
Чистый Python детектор 14 классических паттернов:

| Паттерн | Тип | Реализация |
|---------|-----|------------|
| Doji | Neutral | ✅ По определению: body < 10% диапазона |
| Hammer | Bullish | ✅ Маленькое тело сверху, длинная нижняя тень после даунтренда |
| Inverted Hammer | Bullish | ✅ Маленькое тело снизу, длинная верхняя тень после даунтренда |
| Hanging Man | Bearish | ✅ Как Hammer, но после аптренда |
| Shooting Star | Bearish | ✅ Как Inverted Hammer, но после аптренда |
| Bullish Engulfing | Bullish | ✅ Бычья свеча полностью поглощает предыдущую медвежью |
| Bearish Engulfing | Bearish | ✅ Медвежья свеча полностью поглощает предыдущую бычью |
| Bullish Harami | Bullish | ✅ Маленькая свеча внутри тела предыдущей медвежьей |
| Bearish Harami | Bearish | ✅ Маленькая свеча внутри тела предыдущей бычьей |
| Piercing | Bullish | ✅ Бычья свеча закрывается выше 50% предыдущей медвежьей |
| Dark Cloud Cover | Bearish | ✅ Медвежья свеча закрывается ниже 50% предыдущей бычьей |
| Morning Star | Bullish | ✅ Трёхсвечный паттерн разворота вверх |
| Evening Star | Bearish | ✅ Трёхсвечный паттерн разворота вниз |
| Three White Soldiers | Bullish | ✅ Три последовательные бычьи свечи с ростом |
| Three Black Crows | Bearish | ✅ Три последовательные медвежьи свечи с падением |

### Соответствие оригиналу

**TA-Lib использует:**
- Фиксированные пороги (hardcoded в C коде)
- Возвращает -100, 0, +100
- Не учитывает контекст (тренд до паттерна)

**Моя реализация:**
- Настраиваемые пороги (DOJI_BODY_PCT=0.1, SMALL_BODY_PCT=0.3, LARGE_BODY_PCT=0.6)
- Возвращает 50-100 (strength)
- Учитывает предыдущую свечу для контекста тренда

### ⚠️ Потенциальные проблемы

1. **Пороги отличаются от TA-Lib** — мои пороги подобраны эмпирически, не из оригинала
2. **Нет проверки волатильности** — TA-Lib использует ATR для фильтрации шума
3. **Упрощённая логика тренда** — проверяю только 1 предыдущую свечу, не полноценный тренд

### Рекомендация
⚠️ **Требует backtesting** перед использованием в продакшене. Паттерны могут давать другие сигналы чем TA-Lib.

## 2. CurrencyStrengthMeter

**Файл:** `app/market_data/currency_strength.py`

### Источник идеи
- github.com/EarnForex/Currency-Strength-Lines — MQL4/5 индикатор
- Формула с Forex Factory: https://www.forexfactory.com/thread/367141

### Что реализовано

Расчёт относительной силы 8 валют (USD, EUR, GBP, JPY, CHF, AUD, CAD, NZD) на основе 28 пар.

**Алгоритм:**
```
1. Для каждой из 28 пар: change% = (current - previous) / previous * 100
2. Для каждой валюты: собрать все пары где она участвует
3. Если валюта = base: добавить change%
4. Если валюта = quote: добавить -change% (инвертировать)
5. Усреднить scores для каждой валюты
6. Ранжировать от сильной к слабой
```

### Соответствие оригиналу

**EarnForex индикатор:**
- Использует несколько таймфреймов (MTF)
- Нормализует через RSI
- Имеет smoothing

**Моя реализация:**
- Один таймфрейм (24h change)
- Простое усреднение без RSI
- Без smoothing

### ⚠️ Потенциальные проблемы

1. **Нет MTF** — оригинал смотрит M15, H1, H4, D1 одновременно
2. **Нет нормализации** — большие движения доминируют
3. **Зависит от качества данных** — нужны цены всех 28 пар

### Рекомендация
⚠️ **Упрощённая версия**. Для точного strength meter нужны MTF данные и RSI-based нормализация.

## 3. VolatilityRegimeDetector

**Файл:** `app/risk/volatility_regime.py`

### Источник идеи
- github.com/MehranTaghian/DQN-Trading — RL для трейдинга
- Концепция volatility regimes из академических работ

### Что реализовано

Классификация волатильности в 4 режима:

| Режим | Условие | Position Multiplier |
|-------|---------|---------------------|
| LOW | ATR ratio < 0.5 | 1.2x (больше позиция) |
| NORMAL | 0.5 ≤ ratio < 1.5 | 1.0x |
| HIGH | 1.5 ≤ ratio < 2.5 | 0.6x (меньше позиция) |
| EXTREME | ratio ≥ 2.5 | 0.3x (минимальная) |

**ATR ratio = текущий_ATR / средний_ATR_за_20_периодов**

### Соответствие оригиналу

**DQN-Trading использует:**
- Машинное обучение для определения режима
- Множество features (не только ATR)
- Обучение на исторических данных

**Моя реализация:**
- Простые пороги (rule-based)
- Только ATR
- Без обучения

### ⚠️ Потенциальные проблемы

1. **Пороги произвольные** — 0.5, 1.5, 2.5 не из исследований
2. **Нет адаптации** — пороги фиксированные для всех пар
3. **Только ATR** — не учитывает VIX, spreads, volume

### Рекомендация
✅ **Безопасно использовать** — консервативный подход (уменьшаем позицию при высокой волатильности). Худший случай — упущенная прибыль, не убыток.

## 4. VIXFetcher

**Файл:** `app/data_sources/vix_index.py`

### Источник идеи
- Твой существующий `dxy_index.py`
- Стандартная интерпретация VIX

### Что реализовано

Получение VIX (^VIX) через yfinance с интерпретацией:

| VIX | Режим | Risk Multiplier |
|-----|-------|-----------------|
| < 12 | EXTREME_GREED | 1.2x |
| 12-20 | GREED | 1.0x |
| 20-30 | FEAR | 0.6-0.8x |
| > 30 | EXTREME_FEAR | 0.4x |

### Соответствие оригиналу

Это стандартная интерпретация VIX, широко используемая:
- CNN Fear & Greed Index использует похожие пороги
- 20 = исторический средний VIX
- 30 = порог паники

### ⚠️ Потенциальные проблемы

1. **VIX = S&P 500 волатильность** — не напрямую связан с Forex
2. **Задержка данных** — yfinance даёт delayed данные
3. **Пороги могут устареть** — после 2020 VIX выше в среднем

### Рекомендация
✅ **Можно использовать** как дополнительный индикатор риска, но не как основной.

## 5. AgentPerformanceTracker

**Файл:** `app/agents/performance_tracker.py`

### Источник идеи
- github.com/asavinov/intelligent-trading-bot — концепция feedback loop
- Reinforcement Learning принципы

### Что реализовано

Динамическая корректировка весов агентов на основе результатов сделок:

```
1. После закрытия сделки: записать agent_votes и PnL
2. Для каждого агента:
   - Если голосовал ЗА направление и сделка WIN: +learning_rate
   - Если голосовал ЗА направление и сделка LOSS: -learning_rate/2
   - Если голосовал ПРОТИВ и WIN: -learning_rate (был неправ)
   - Если голосовал ПРОТИВ и LOSS: +learning_rate/2 (был прав)
3. Нормализовать веса до суммы 1.0
4. Ограничить веса [min_weight, max_weight]
```

**Параметры по умолчанию:**
- learning_rate = 0.02 (2% за сделку)
- min_weight = 0.05 (минимум 5%)
- max_weight = 0.40 (максимум 40%)
- min_trades_for_adjustment = 10

### Соответствие оригиналу

**Intelligent-trading-bot использует:**
- Более сложную систему с memory buffer
- Policy gradient методы
- Continuous action space

**Моя реализация:**
- Простой incremental update
- Discrete adjustments
- Без neural networks

### ⚠️ Потенциальные проблемы

1. **Медленная адаптация** — 2% за сделку = нужно 50 сделок для значимого изменения
2. **Не учитывает размер PnL** — WIN +$10 и WIN +$1000 одинаково влияют
3. **Recency bias** — последние сделки влияют так же как старые
4. **Нет decay** — ошибки агента год назад всё ещё влияют

### Рекомендация
⚠️ **Экспериментальный модуль**. Нужно:
- Добавить вес PnL в расчёт
- Добавить time decay (старые сделки меньше влияют)
- Протестировать на исторических данных

## Что нужно для продакшен-готовности

### CandlestickPatterns
1. Сверить пороги с TA-Lib исходниками
2. Добавить ATR фильтрацию (игнорировать паттерны в низкой волатильности)
3. Backtesting на исторических данных EURUSD, GBPUSD

### CurrencyStrength
1. Добавить multi-timeframe (M15 + H1 + H4)
2. Нормализация через RSI или Z-score
3. Smoothing (EMA вместо простого среднего)

### PerformanceTracker
1. Weighted PnL (большие победы/потери влияют больше)
2. Time decay (exponential decay для старых сделок)
3. Минимум 30-50 сделок перед активацией
